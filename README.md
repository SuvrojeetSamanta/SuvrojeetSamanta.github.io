# SuvrojeetSamanta.github.io

Personal portfolio for Suvrojeet Samanta, a B.Tech Civil Engineering student at Heritage
Institute of Technology, Kolkata.

## Updating content

Most visible portfolio content is configured in `script.js`. Update the profile and content
arrays near the top of the file. To add a project, add an object to the `projects` array:

```js
{
  title: 'Project title',
  description: 'A short description of the work.',
  meta: 'Category · Tools · Year',
  href: 'https://example.com',
  action: 'View project',
}
```

The project cards are rendered automatically. The site intentionally contains no pre-filled
GitHub projects.
